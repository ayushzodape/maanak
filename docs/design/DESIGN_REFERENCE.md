    # Maanak Design Reference
    
    The AI Studio prototype is the primary visual reference
    for the Maanak product.
    
    Codex should preserve its visual language when implementing
    the production application.
    
    ## Preserve
    
    - color palette
    - typography
    - spacing
    - card styling
    - border radius
    - shadows
    - navigation style
    - icon style
    - button style
    - information hierarchy
    - animations
    - overall visual personality
    
    ## Do not blindly preserve
    
    If the prototype contains:
    - fake data
    - incorrect workflows
    - missing states
    - misleading compliance claims
    - technically impossible interactions
    
    preserve the visual language but implement the correct
    behavior according to the canonical product specification.
    
    ## Priority
    
    Product requirements > functional correctness > accessibility
    > responsive behavior > visual fidelity > decorative details.
